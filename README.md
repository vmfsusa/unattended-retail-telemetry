# Unattended Retail Telemetry — Open Dataset

An open dataset of anonymized, aggregated telemetry from VMFS USA smart vending machines: transaction counts by product category and payment type, restock cadence, and energy-consumption readings, with a full data dictionary and methodology note.

**Status:** First release in preparation. The dataset, data dictionary, and methodology will be published here under a CC-BY-4.0 license.

**Intended use:** Academic research, theses, and industry analysis of unattended retail. If you use this data, please cite VMFS USA as the provider.
